## Реализованный функционал

### Безопасность и авторизация
- Авторизация и регистрация пользователей.
- Разграничение прав доступа (роли: `Admin` и `User`).
- Хэширование паролей алгоритмом SHA1 перед сохранением в БД.
- Защита от подбора паролей: капча (с запретом копирования/вставки) после 3-х неверных попыток входа.
- Смена пароля пользователем с проверкой валидации.
- Запрос подтверждения при выходе из приложения и удалении записей.

### Роль «Пользователь» (Кассир)
- Просмотр истории собственных продаж (чеков).
- Сортировка чеков по дате (возрастание/убывание).
- **Оформление новой продажи (пробитие чека):**
  - Добавление топлива (с указанием количества литров).
  - Добавление сопутствующих товаров и услуг (мойка, кофе и т.д.).
  - Выбор способа оплаты (наличные, карта и т.д.).
  - Автоматический подсчет итоговой суммы и сохранение чека в БД (таблицы `Sales` и `SaleItems`).

### Роль «Администратор»
- **Управление сотрудниками (CRUD):** добавление, редактирование, удаление пользователей.
- **Управление продажами (CRUD):** просмотр всех чеков, редактирование, удаление (с каскадным удалением позиций чека).
- **Аналитика и графики:** просмотр диаграмм сумм продаж по выбранному сотруднику с группировкой по способам оплаты.
- **Экспорт данных:** выгрузка отчетов в Microsoft Word (с сохранением в .docx и .pdf) и Microsoft Excel (.xlsx).

### Интерфейс и UX
- 3 динамические темы оформления (Светлая, Темная, Альтернативная), сохраняющиеся при работе.
- Единый стиль по брендбуку (шрифт Open Sans, фирменные цвета АЗС).
- Плейсхолдеры (подсказки внутри полей ввода).
- Всплывающие подсказки (ToolTips) для всех интерактивных элементов.
- Валидация вводимых данных (проверка длины пароля, наличие цифр, запрет ввода букв в числовые поля).
- Динамические заголовки страниц.

## Структура базы данных
База данных `DB_Savrasov_GasStation` состоит из 11 таблиц, связанных между собой (включая связующую `SaleItems`):
1. `Users` (Сотрудники АЗС)
2. `FuelTypes` (Виды топлива)
3. `Tanks` (Резервуары)
4. `Pumps` (Колонки)
5. `Customers` (Клиенты)
6. `PaymentMethods` (Способы оплаты)
7. `Services` (Услуги/Товары)
8. `Suppliers` (Поставщики)
9. `Deliveries` (Поставки)
10. `Sales` (Чеки/Продажи)
11. `SaleItems` (Позиции чеков)
